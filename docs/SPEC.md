# 스크리너·앱 규칙 원문 (사용자 지시문)

이 문서는 사용자가 준 규칙을 그대로 옮긴 것입니다. 코드가 이 규칙과 다르면 코드가 틀린 것입니다.
숫자 파라미터의 기본값은 `config.yaml`에 있고, 임의로 바꾸지 않습니다.

## 앱 구조
대분류 = 미국주식 → 국내주식, 각 시장 안에 단기 → 중기 → 장기.

## 최종 결과물
1. 자동으로 종목을 골라 결과 파일을 GitHub에 올리는 스크리너 (단기·중기는 매일, 장기는 월 1회, 인사이트는 주 1회. GitHub Actions)
2. 결과를 보여주는 안드로이드 앱 APK (Flutter)
3. 한국어 README

## 2. 데이터
- 미국 종목 리스트: NASDAQ Trader `nasdaqlisted.txt`, `otherlisted.txt`. ETF, 테스트 종목, 워런트·유닛·우선주·권리 제외. 보통주만
- 장기용 유니버스: S&P 500 + 나스닥 100 (위키피디아, 실패 시 캐시)
- 가격: yfinance 일봉 OHLCV. 스크리너는 최근 400거래일, 백테스트는 2015-01-01부터. 배치 다운로드, 재시도, parquet 캐시, 증분 업데이트
- 재무: yfinance `Ticker.info` (월 1회, 장기 유니버스만). 실패 시 SEC XBRL companyfacts로 보완
- 전체를 못 받으면 멈추지 말고 받은 만큼으로 진행하되 몇 개 중 몇 개인지 보고

## 3. 지표 (일봉, 해당일 종가까지)
- ADR20: 최근 20일 (고가/저가 − 1) 평균, %
- DV20: 최근 20일 (종가 × 거래량) 평균
- Vol20: 최근 20일 평균 거래량
- R1M / R3M / R6M / R12M: 21 / 63 / 126 / 252 거래일 전 종가 대비 수익률. R12M_ex1 = 최근 1개월 제외 12개월 수익률
- SMA10 / 20 / 50 / 150 / 200, 52주 고가 / 저가

## 4. 미국 단기 (며칠 ~ 2주)
### 4-1 유니버스 (매일 다시 계산)
- 종가 ≥ $2, DV20 ≥ $1,000,000, ADR20 ≥ 5%
- R1M, R3M, R6M 중 하나라도 그날 전체 종목 중 상위 2%

### 4-2 셋업 A — 돌파 (당일을 t, 트리거 외 판단은 t−1까지 데이터로)
- 급등: t−60 ~ t−10 구간 최고가 = peak. peak 이전 40일 최저가(trough) 대비 peak/trough − 1 ≥ 30%
- 횡보: peak 이후 t−1까지 10~40 거래일. 그 구간 최고가 = box_high, 최저가 = box_low, box_high/box_low − 1 ≤ 25%
- 거래량 감소: 최근 10일 평균 거래량 < peak 직전 10일 평균 거래량
- 추세: t−1 종가 ≥ SMA20 또는 SMA20 대비 1×ADR 이내, SMA10이 5일 전보다 높음
- 트리거: t 고가 > box_high. 진입가 = max(t 시가, box_high). box_high보다 5% 넘게 높으면 건너뜀
- 스크리너는 "내일 box_high 돌파를 기다리는 종목"을 트리거가와 함께 출력

### 4-3 셋업 B — 에피소딕 피벗 (EP)
- 갭: t 시가 ≥ t−1 종가 × 1.10, 단 × 1.40 초과면 건너뜀
- 거래량: t 거래량 ≥ Vol20 × 5 (장중 실행 시 "지금까지 누적 거래량을 하루치로 환산"해서 비교)
- 소외: t−1 기준 R3M ≤ +25%
- 진입가: t 시가 × 1.02. t 고가가 못 미치면 건너뜀
- A와 겹치면 EP로 분류

### 4-4 청산 (A, B 공통)
- 손절폭: max(ADR20, 3%)를 3~10%로 제한. stop = 진입가 × (1 − 손절폭)
- 진입일: 종가 < stop이면 손절. 다음날부터: 저가 < stop이면 stop에서 청산, 시가부터 stop 아래면 시가에서 청산
- 부분 익절: 진입 후 3번째 거래일 종가에 50% 매도, 남은 물량 stop을 진입가로 올림
- 나머지: 종가 < SMA10이면 전량 청산. 최대 보유 60거래일

### 4-5 자금
- 기본 자산 $700 (앱 설정에서 변경)
- 1회 리스크 = 자산의 5% → 수량 = floor(자산 × 0.05 ÷ (진입가 − stop))
- 한 종목 최대 비중 50%(앱 설정에서 100%까지), 정수 주만, 레버리지 없음, 동시 최대 3종목, 신호가 많으면 R3M 높은 순
- 비용(백테스트용): 수수료 0.25% 편도 + 슬리피지 0.2% 편도
- 출력 `output/us_short.json`, `output/us_short_ep.json`. 필드: `date, ticker, setup, trigger_price, stop_price, adr20, r1m, r3m, r6m, dv20, score`

## 5. 미국 중기 (몇 주 ~ 몇 달) — 추세 눌림목
- 유니버스: 종가 ≥ $5, DV20 ≥ $5,000,000, ADR20 2~8%
- 추세(미너비니 트렌드 템플릿): 종가 > SMA50 > SMA150 > SMA200, SMA200이 1개월 전보다 높음, 52주 저가 대비 +30% 이상, 52주 고가 대비 −25% 이내, R6M이 유니버스 상위 20%
- 눌림: 최근 20일 고점 대비 −5% ~ −15%, 종가 ≥ SMA50, 종가가 SMA20 대비 ±1×ADR 이내
- 진입 트리거: 눌림 상태에서 당일 종가 > 전일 고가 (반등 첫날). 진입가 = 당일 종가. 스크리너는 "내일 시가 매수 후보"로 출력
- 손절: 최근 10일 최저가 × 0.99, 단 진입가 대비 −8% 이내로 제한
- 익절: +2R에 절반 매도, 나머지는 종가 < SMA50이면 전량 청산. 최대 보유 120거래일
- 자금: 1회 리스크 자산의 2%, 동시 최대 5종목, 한 종목 최대 30%, 신호가 많으면 R6M 높은 순. 중기 자금은 단기 자금과 별도
- 출력 `output/us_mid.json`. 필드: `date, ticker, entry_price, stop_price, target_2r, adr20, r6m, dist_sma20, score`

## 6. 미국 장기 (몇 달 ~ 몇 년) + 인사이트
### 장기 후보 (매월 첫 거래일 갱신)
- 유니버스: S&P 500 + 나스닥 100. 금융주는 부채 조건 제외
- 재무 조건 (TTM/최근 연간): ROE ≥ 15%, 매출 성장(yoy) ≥ 8%, 영업이익률 ≥ 10%, 잉여현금흐름 > 0, 부채/자본 ≤ 150%
- 추세 조건: 종가 > SMA150 > SMA200, SMA200이 5개월 전보다 높음, 52주 고가 대비 −25% 이내, 52주 저가 대비 +30% 이상
- 상대강도: R12M_ex1이 유니버스 상위 30%
- 밸류 가드: PEG ≤ 2.5 또는 forward PE ≤ 35 중 하나 만족
- 점수 = 재무 순위 50% + R12M_ex1 순위 50%. 상위 20종목을 `output/us_long.json`으로 (티커, 회사명, 점수, 통과한 조건, ROE, 매출성장, 영업이익률, PEG, 52주 고가 대비 %, 다음 실적 발표일)
- 편입·교체(월 1회): 상위 5종목 동일비중. 보유 종목이 종가 기준 SMA200 아래 10거래일 연속이거나 순위 10위 밖으로 밀리면 교체 후보로 표시. 앱은 표시만 하고 매매는 사용자가 한다

### 인사이트 (매주 월요일 갱신, `output/us_insight.json`)
- 시장 온도: SPY 종가 vs SMA200, S&P 500 종목 중 SMA200 위 비율(브레드스). 신호는 두 가지만: "지금 투입" (SPY > SMA200 이고 브레드스 > 50%) / "3개월 분할 투입" (그 외)
- 섹터 순위: 11개 섹터 ETF의 1·3·6개월 수익률 표 (ETF는 지표로만)
- 이번 달 변화: 장기 후보 신규 진입·이탈, 상위 5종목의 2주 내 실적 발표 예정
- 선택: Claude API 키가 있으면 매주 인사이트 숫자를 바탕으로 한국어 3~5줄 요약을 생성해 맨 위에 표시. 키가 없으면 숨김

## 7. 스크리너 + 자동 실행
- 명령 하나: `python screener.py` (오늘 돌 것을 알아서 실행). 부분 실행: `--short`, `--ep`, `--mid`, `--long`, `--insight`, `--market us|kr`
- EP는 yfinance 1분봉으로 당일 시가와 현재까지 거래량 사용. 1분봉 없는 종목은 건너뜀
- `.github/workflows/screener.yml` 실행 시각 (cron은 UTC, 서머타임 고려):
  - 평일 미국장 마감 후: 단기 돌파 대기 + 중기
  - 평일 미국장 개장 30분 뒤: EP
  - 매월 첫 거래일: 장기
  - 매주 월요일: 인사이트
- 데이터는 actions/cache로 증분 업데이트. 결과 json 커밋. Yahoo 오류 시 이전 파일 유지

## 8. 안드로이드 앱 (Flutter, 한국어 UI)
- 하단 메뉴 4개: 종목 / 보유 / 인사이트 / 설정
- 종목 화면: 시장 전환(미국 | 국내 — 국내는 "준비 중"), 세그먼트 단기 | 중기 | 장기
  - 단기: 목록 2개(돌파 대기, EP). 항목: 티커, 트리거가, 손절가, 수량 제안, ADR, 3개월 수익률
  - 중기: 티커, 진입가, 손절가, 2R 목표가, 수량 제안, 6개월 수익률, 20일선 대비 %
  - 장기: 상위 20 (점수순, 통과 조건 배지). 상단 배분표: 장기 자금을 상위 5종목에 균등 배분해 종목별 금액·수량
  - 당겨서 새로고침, 갱신 시각 표시
- 보유 화면: 종목 입력 시 단기/중기/장기 선택, 진입가·진입일·수량, 폰에만 저장. Yahoo chart API로 현재가와 이동평균을 받아 신호 표시
  - 단기: 손절 도달 / 3거래일째 절반 매도 / SMA10 이탈 / 60일 초과
  - 중기: 손절 도달 / +2R 절반 매도 / SMA50 이탈 / 120일 초과
  - 장기: SMA200 아래 10거래일 / 순위 10위 밖
- 인사이트 화면: 시장 온도, 섹터 표, 이번 달 변화. 상단에 현재 자산 / 목표 자산 진행률
- 설정 화면: 시장별·기간별 자금 (미국 단기 USD 기본 700, 중기, 장기 기본 500만 원 상당, 국내는 원화), 한 종목 최대 비중(기본 50%), 동시 보유 종목 수, 목표 자산(기본 1,000만 원), 알림 시각. 데이터 주소는 기본값 숨김
- 차트 화면: TradingView 무료 임베드 위젯을 WebView로 (출처 표시). 안 되면 Yahoo 데이터로 캔들 + SMA10/20/50/200 + 트리거가·손절가 선. "TradingView 앱에서 열기", "증권사 앱에서 열기" 버튼
- 알림: Firebase 없이. 정해진 시각(기본 한국시간 07:00 = 단기 대기 + 중기 후보 + 보유 신호, 미국장 개장 30분 뒤 = EP, 매월 1일 = 장기 갱신, 매주 월요일 = 인사이트 신호가 바뀌었을 때)에 결과 파일을 확인해 알림(알람 매니저 + 로컬 알림). Android 12+ 정확한 알람 권한과 배터리 최적화 제외를 첫 실행 때 안내

## 9. APK 빌드·배포
- GitHub Actions에서 `flutter build apk --release` → Releases에 `app-release.apk`
- 서명용 keystore를 한 번 만들어 Actions secrets에 저장하고 매번 같은 키로 서명
- README.md에 링크, 설치법, 매일 보는 법을 한국어로

## 10. 백테스트 (선택 — 요청 시)
- `python backtest.py --short` / `--mid`: 2016-01-01 ~ 오늘, 위 규칙 그대로. 단기 초기 자산 $700, 중기 $3,500
- 인샘플 2016~2020 / 아웃오브샘플 2021~ / 전체: 총수익률, CAGR, MDD, 거래 수, 승률, 손익비, 프로핏팩터, 기대값(R), 평균 보유일. 셋업별·연도별. 상위 10개 거래 비중. 리스크 비율 3단계. 몬테카를로 1,000회

## 11. 국내주식 (미국 버전이 앱에서 알림까지 정상 작동한 뒤)
