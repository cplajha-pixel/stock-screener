# 주식 스크리너 + 안드로이드 앱

미국 주식(단기 · 중기 · 장기)을 매일 자동으로 골라 GitHub 에 올리고, 안드로이드 앱으로 보는 도구입니다.
국내주식은 준비 중입니다.

- 결과 파일: [`output/`](output/) 폴더 (json)
- 앱 다운로드: **[Releases → app-release.apk](https://github.com/cplajha-pixel/stock-screener/releases/latest)**
- 자동 실행 로그: [Actions](https://github.com/cplajha-pixel/stock-screener/actions)

---

## 1. 앱 설치 (안드로이드)

1. 폰에서 이 링크를 엽니다: https://github.com/cplajha-pixel/stock-screener/releases/latest
2. `app-release.apk` 를 눌러 다운로드합니다.
3. 다운로드한 파일을 누르면 "출처를 알 수 없는 앱" 경고가 나옵니다 → **설정 → 이 출처 허용** 을 켜고 뒤로 가서 다시 **설치**.
4. 앱을 열면 권한 안내가 나옵니다. **설정하기** 를 누르고 알림 / 알람 및 리마인더 / 배터리 최적화 제외를 모두 **허용** 합니다.
   - 삼성 폰은 추가로 *설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱* 에 이 앱을 넣어 두면 알림이 더 안정적입니다.
5. 업데이트: 같은 링크에서 새 APK 를 받아 덮어 설치하면 됩니다 (같은 키로 서명하므로 지우지 않아도 됨).

## 2. 매일 보는 법

| 시각 (한국) | 무엇 | 어디서 |
|---|---|---|
| **07:00** 알림 | 어젯밤 미국장 마감 기준 **단기 돌파 대기** + **중기 후보** + **보유 종목 신호** | 앱 알림 → 종목 / 보유 탭 |
| 미국장 개장 30분 뒤 (서머타임 23:00 / 겨울 00:00) | **EP(에피소딕 피벗)** 후보 | 앱 알림 → 종목 탭 → 단기 → EP |
| 매월 첫 거래일 | **장기 후보 상위 20** 갱신 + 상위 5 배분표 | 종목 탭 → 장기 |
| 매주 월요일 | **인사이트** (시장 온도, 섹터, 이번 달 변화) | 인사이트 탭 |

### 종목 탭
- 상단에서 **미국 | 국내(준비 중)** 시장, 아래에서 **단기 | 중기 | 장기** 를 고릅니다.
- **단기 · 돌파 대기**: 내일 *트리거가* 를 넘으면 진입, *손절가* 는 정해져 있고, *수량* 은 설정의 단기 자금과 리스크 5% 로 계산한 제안값입니다. 트리거가보다 5% 넘게 높으면 건너뜁니다.
- **단기 · EP**: 시가 갭 +10~40% 에 거래량이 평소 5배 이상인 종목. *진입가* = 시가 × 1.02. "진입가 도달" 표시가 있으면 이미 그 가격을 찍은 것입니다.
- **중기**: 추세 눌림목 반등 첫날. *진입가* 는 어제 종가(내일 시가 매수 후보), *2R 목표* 에서 절반 매도.
- **장기**: 재무 + 추세 + 상대강도 + 밸류 조건을 모두 통과한 상위 20. 맨 위 배분표는 설정의 장기 자금을 상위 5 종목에 균등 배분한 금액·수량입니다. 앱은 표시만 하고 매매는 직접 합니다.
- 종목을 누르면 **차트** (TradingView 위젯) 와 "TradingView 앱에서 열기 / 증권사 앱에서 열기 / 보유 추가" 버튼이 나옵니다.
- 아래로 당기면 새로고침, 상단에 기준일과 갱신 시각이 보입니다.

### 보유 탭
- **+** 로 보유 종목을 넣습니다 (단기/중기/장기 구분, 진입가, 진입일, 수량, 손절가). **폰에만 저장** 되고 어디에도 올라가지 않습니다.
- 현재가와 이동평균을 받아 구분별 신호를 빨간 글씨로 보여줍니다.
  - 단기: 손절 도달 / 3거래일째 절반 매도 / SMA10 이탈 / 60일 초과
  - 중기: 손절 도달 / +2R 절반 매도 / SMA50 이탈 / 120일 초과
  - 장기: SMA200 아래 10거래일 / 순위 10위 밖
- 절반 매도를 했으면 **"절반 매도 완료"** 를 체크하세요. 길게 누르면 수정, 휴지통은 삭제.

### 근거 보기 (종목 카드의 "근거 보기" 버튼)
- **왜 뽑혔나**: 규칙의 각 조건에 실제 숫자를 대입한 문장 (급등 %, 횡보 일수·폭, 거래량 감소, 이동평균, 트리거·손절 계산).
- **뉴스**: 세이브티커(saveticker.com) 공개 API에서 종목별 최근 헤드라인·요약. 누르면 원문. 로그인 불필요.
- **애널리스트·수급**: 의견, 목표가 평균과 괴리, 매수/중립/매도 수, 공매도 비율, 기관 보유, 다음 실적일 (실적 10일 이내면 경고).
- **재무건전성 해석**: 부채비율·유동비율·잉여현금흐름·영업이익률·매출성장·ROE·순이익률을 A~F 등급과 한 줄 설명으로, 종합 등급 + 피오트로스키 F점수(0~9) + 알트만 Z(부도 위험 구간). 차트 화면 "재무 해석" 탭에 자세히, 연간 실적 표와 밸류에이션 해석 포함.
- **Claude 해석**: 루틴(아래)이 설정되어 있으면 종목별 긍정/중립/부정 의견과 2~4문장 해석이 붙습니다.
- ★ 표시 = **오늘의 1픽** (돌파 대기 후보 중 [3개월 수익률 + 횡보 폭 + 거래량 감소율 + 트리거가 근접도] 평균 순위 1위). 인사이트 탭 → 🏆 에서 **성적표** (다음 날 발동 여부, 규칙대로 자동 채점한 손익, 누적 승률).

### 인사이트 탭
- 맨 위: 현재 자산 / 목표 자산 진행률.
- **오늘의 해석** (Claude 루틴이 쓴 글, 설정 시): 거시·뉴스가 오늘 후보들에 어떤 환경인지, 지켜볼 지표, 1픽 코멘트.
- **오늘의 시장** (매일 갱신): 숫자가 뜻하는 것(한 줄 설명), 거시 지표 표(S&P·나스닥·소형주·VIX·10년물·달러·유가·금·비트코인·구리 1일/1주/1개월), 최근 발표된 미국 경제지표(FRED).
- **지표·이벤트 일정** (앱을 열 때 실시간 조회, 한국시간, ★ 중요도): 발표치는 "[속보]" 뉴스로 바로 올라옵니다.
- **주요 뉴스** (실시간): 세이브티커 최신 헤드라인. 누르면 원문.
- **이번 주 시장 온도** (매주 월요일): "지금 투입" (SPY > SMA200 이고 S&P 500 중 SMA200 위 비율 > 50%) 또는 "3개월 분할 투입", 섹터 ETF 1·3·6개월 수익률 표, 이번 달 장기 후보 신규/이탈, 상위 5 의 2주 내 실적 발표.
- 맨 아래 **세이브티커 열기**: 증권사 리포트는 세이브티커에 본인이 로그인해서 봅니다 (앱은 비밀번호를 다루지 않음).

### 장중 실시간 알림 (토스증권 오픈API, PC 스캐너)
- **무엇**: 미국 정규장(서머타임 22:30~05:00, 겨울 23:30~06:00 KST) 동안 **1분마다** 토스 랭킹(상승률·거래량·거래대금 상위)을 받아 우리 유동성 기준으로 거른 뒤 1분봉으로 판정합니다.
  - **EP**: 시가 갭 +10~40%, 누적 거래량(하루치 환산) 20일 평균 5배 이상, 3개월 수익률 25% 이하 → 진입가 = 시가 × 1.02, 도달 시 한 번 더 알림
  - **단타**: 전일 대비 +5% 이상, 거래량 3배 이상, 당일 고가의 2% 이내 (횡보 종목이 아니라 "지금 거래량 터지며 오르는 종목")
  - 종목당 하루 1번 알림. 숫자는 `config.yaml` 의 `us_live`.
- **어디서**: 토스 API는 등록한 IP에서만 되므로 **집 PC**에서 돕니다. 작업 스케줄러 `StockScreenerLive` 가 매일 22:15 PC를 깨워 `scripts/run_live_scanner.cmd` 를 실행하고, 마감 후 스스로 끝납니다. 로그: `data/live_scanner.log`.
  - PC가 22:15에 잠들어 있으면 깨어나야 합니다. 안 깨어나면 *설정 → 시스템 → 전원 → 절전* 에서 절전 해제 타이머 허용을 켜 주세요.
- **어떻게 전달**: 스캐너가 알림을 ntfy.sh 의 비공개 토픽(키 파일 `toss.env` 의 `NTFY_TOPIC`)으로 보내고, 앱이 정규장 시간에만 "장중 감시 중" 상태로 1분마다 확인해 팝업을 띄웁니다. 앱 설정 → *장중 실시간 알림 → 알림 토픽* 에 같은 값을 넣어야 합니다.
- **앱 장중 탭**: 1분마다 갱신되는 실시간 후보 목록(현재가·등락·거래량 배수·고가·EP 진입가·손절·수량)과 오늘 알림 기록. 종목을 누르면 차트.
- **매매**: 알림을 보고 토스 앱에서 직접 주문합니다. 손절·목표는 토스 **조건주문(OCO)** 에 앱의 "주문에 넣을 값"을 넣어 두면 밤에도 자동 체결됩니다.
- **키 파일** `C:\Users\User\stock-screener-keys\toss.env` (저장소에 없음): `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`, `NTFY_TOPIC`. 토스 WTS → 설정 → Open API 에서 발급, **허용 IP 관리**에 PC 공인 IP 등록 필요.

### 주문에 넣을 값 (근거 펼침 / 차트 화면)
- 매수 지정가(트리거가, 최대 +5%), 손절 감지가, 예상 체결가(슬리피지 가정, 설정에서 변경), 2R 목표 감지가, 수량. 누르면 복사됩니다.
- 카카오페이증권 등의 **시세감지주문**에 그대로 넣으면 밤에도 규칙대로 체결됩니다. 앱은 장중 감시를 하지 않습니다 (증권사 기능이 더 정확).

### 지표 발표 알림
- 세이브티커 캘린더의 ★★★ 지표(설정에서 ★★ 이상으로 변경 가능)를 발표 시각 **+1분**에 확인해 "[속보]" 뉴스의 실제 수치를 알림으로 보냅니다. 속보가 아직 없으면 **+5분**에 다시 확인합니다.

### Claude에게 물어보기 (API 불필요)
- 인사이트 탭 맨 위 버튼을 누르면 오늘 후보·근거·거시·뉴스가 질문 글로 만들어져 **클로드 앱**(공유 창에서 선택)에 전달됩니다. 구독으로 답을 받으므로 API 키·토큰 결제가 필요 없습니다. 클로드 앱이 없으면 클립보드에 복사되고 claude.ai 가 열립니다.
- (선택) 완전 자동을 원하면 claude.ai 의 루틴 기능으로 매일 `output/us_analysis.json` 을 쓰게 할 수 있습니다. 프롬프트 원문은 [`docs/ROUTINE_PROMPT.md`](docs/ROUTINE_PROMPT.md), GitHub 계정 연결이 필요합니다.

### 설정 탭
- 시장별·기간별 자금 (미국 단기 기본 $700, 중기 $3,500, 장기 $3,600 ≈ 500만 원), 한 종목 최대 비중 (기본 50%, 전량 매매면 100), 동시 보유 종목 수, 목표 자산 (기본 1,000만 원), 알림 시각.
- **알림 테스트** / **권한 확인** / **지금 아침 점검 실행** 버튼으로 바로 확인할 수 있습니다.
- 데이터 주소는 "고급" 안에 있습니다 (보통 건드릴 일 없음).

## 3. 규칙 요약

모든 숫자는 [`config.yaml`](config.yaml) 에 있습니다.

- **단기 유니버스**: 종가 ≥ $2, 20일 평균 거래대금 ≥ $1M, ADR20 ≥ 5%, 1/3/6개월 수익률 중 하나라도 전체 상위 2%
- **돌파(A)**: 30% 이상 급등 → 10~40일 횡보(폭 25% 이내) → 거래량 감소 → 20일선 위 → 횡보 고점 돌파
- **EP(B)**: 시가 갭 +10~40%, 거래량 20일 평균 5배 이상, 직전 3개월 수익률 ≤ 25%
- **청산**: 손절 max(ADR20, 3%) 를 3~10% 로 제한, 3번째 거래일 절반 매도 후 손절가를 진입가로, 종가 < SMA10 전량, 최대 60일
- **중기**: 종가 ≥ $5, 거래대금 ≥ $5M, ADR 2~8%, 미너비니 트렌드 템플릿, 20일 고점 대비 −5~−15% 눌림, 반등 첫날 진입, 손절 10일 저가 × 0.99 (−8% 한도), +2R 절반, SMA50 이탈 전량, 최대 120일
- **장기**: S&P 500 + 나스닥 100, ROE ≥ 15%, 매출성장 ≥ 8%, 영업이익률 ≥ 10%, FCF > 0, 부채/자본 ≤ 150% (금융 제외), 추세·상대강도·밸류 가드, 점수 = 재무 순위 50% + 12개월(최근 1개월 제외) 수익률 순위 50%

## 4. 직접 돌리기 (선택)

```bash
pip install -r requirements.txt
python screener.py            # 오늘 돌 것을 알아서 실행 (단기+중기+근거+오늘의 시장, 첫 거래일 장기, 월요일 인사이트)
python screener.py --short    # 단기 돌파 대기만
python screener.py --ep --force   # EP (장중이 아니어도 강제)
python screener.py --mid --long --insight --context --daily
python backtest.py --short    # 백테스트 → output/report_short.md (1픽 변형 포함)
python backtest.py --mid --long
```

백테스트 결과: [`output/report_short.md`](output/report_short.md), [`report_mid.md`](output/report_mid.md), [`report_long.md`](output/report_long.md)

GitHub Actions ([`.github/workflows/screener.yml`](.github/workflows/screener.yml)) 가 평일 미국장 마감 후와 개장 30분 뒤에 자동으로 돌리고 결과를 커밋합니다.
Actions 탭 → screener → **Run workflow** 로 수동 실행도 됩니다.

- 상장폐지 종목이 빠져 있어 백테스트 결과는 실제보다 좋게 나옵니다(생존 편향).
- 이 도구는 후보를 보여줄 뿐이며 매매 판단과 책임은 사용자에게 있습니다.
